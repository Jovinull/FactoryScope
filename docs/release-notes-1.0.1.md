# FactoryScope 1.0.1 [v160]

FactoryScope 1.0.1 is a correctness patch for the 1.0 release. It adds no features.

This update closes the live inspector when its target leaves current fog visibility, revalidates Inspect and Locate actions from older reports, and keeps PowerScope overlay geometry tied to the report snapshot. Previously captured snapshot evidence may remain visible, but it cannot refresh or navigate into currently hidden state.

Targets Mindustry Build 160 and was validated against v8 Build 160.5. Android runtime/touch and remote multiplayer behavior remain independently unvalidated.

Install through Mindustry's Mods screen or download `FactoryScope.jar` from the [GitHub releases](https://github.com/Jovinull/FactoryScope/releases).
