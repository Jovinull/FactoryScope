# Showcase captures

These PNGs are unedited screenshots of FactoryScope 1.3.0 running in the official Mindustry v160.7
desktop client. The acceptance fixtures create the displayed factory states; the images are captured
directly from the game UI, not reconstructed or composited.

| File | What it shows |
| --- | --- |
| `area-diagnostics.png` | Grouped current findings for a selected area. |
| `network-overlay.png` | Structural resource-route overlay in the game world. |
| `payload-network.png` | Network resource filter and overlay for a configured payload conveyor/router route. |
| `reconstructor-payload-trace.png` | Dagger payload traced through a conveyor to a Reconstructor that accepts the upgrade input. |
| `unit-cargo-trace.png` | Sand Supply Trace through a same-team Unit Cargo loader and configured unload point. |
| `supply-trace.png` | Reachable producer endpoints alongside known route terminations. |
| `power-scope.png` | Separate engine power graphs and their grid-level state. |
| `liquid-scope-gas.png` | A structural route view for an Erekir gas resource. |
| `liquid-filter.png` | Resource choices exposed by a liquid-filter consumer. |
| `production-drill.png` | Drill status, production estimate, ore, and optional inputs. |
| `production-turret-idle.png` | A loaded turret ready to fire with no target in range. |
| `production-generator.png` | Generator diagnostics for missing fuel and its power grid. |
| `production-unit-factory.png` | A selected unit plan with its missing inputs and power requirement. |
| `transport-armored-item-trace.png` | An item route that includes an Armored Conveyor. |
| `transport-unloader-bridge-trace.png` | An item route through an Unloader and Duct Bridges. |

The screenshots are retained as evidence of shipped UI rather than as decorative map art. They do
not imply Android or remote-multiplayer validation.
